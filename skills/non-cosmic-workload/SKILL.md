# 非COSMIC评估工作量填报

## 工作流程

生成非COSMIC评估工作量填报表涉及以下步骤：

1. **收集需求信息**：获取项目名称、需求名称、需求编号、项目序号
2. **识别工作类型**：将工作内容归类为配置/数据库操作/多系统联调三大类之一
3. **确定内容属性**：根据工作细节匹配对应的内容属性小类
4. **拆解工作颗粒度**：以"不可细分的完整业务处理过程"为标准，逐条列出工作内容
5. **核算人天**：逐项评估并填写送审人天（总人天，非人数）
6. **生成Excel**：按规范格式输出xlsx文件

## 核心规则

### 工作类型与内容属性（必选项，3选1）

| 大类 | 可选内容属性 |
|------|-------------|
| **配置** | 通过配置操作满足新需求 / OU（组织单位）的增删改 / 公共平台标准接口接入-平台侧 / 公共平台标准接口接入-接入侧 / 利用流程引擎与脚本配置、代码开发增加新的流程节点 / 系统架构升级及调整 |
| **数据库操作** | 支撑类报表制作 / 数据迁移 / 数据库表维护 / 性能调优 |
| **多系统联调** | 开发侧多系统联调 / 配合侧系统调测 |

### 填写规范

- **项目名称**：与软件工作量评估送审材料中的项目名称保持一致
- **颗粒度标准**：每项工作应详细到包含一个不可细分的完整业务处理过程
- **人天规则**：K列送审人天 = 此项工作耗费的总人天。例如：4人投入5天 = 20人天（填20，不是4）
- **合并单元格**：如一条需求包含多个工作类型，A-E列（需求名称/大类/小类/工作名称）按需求合并；F-L列（详细描述/人天等）逐行填写
- **单表原则**：一个需求的所有非COSMIC工作内容填写在同一张表格中
- **文件命名**：`非COSMIC评估工作量填报-项目序号XXX-需求序号YYY.xlsx`

### 排除项（不属于非COSMIC开发工作量）

- 仅通过界面拖拽生成报表
- 仅利用现有流程引擎配置界面新增/修改/删除流程节点（不涉及代码开发、脚本配置）
- 单纯通过IT系统用户管理功能进行增删改、权限配置（属于维护性工作）

## Excel输出格式

生成的Excel应包含以下列：

| 列 | 字段名 | 说明 |
|----|-------|------|
| A | 需求名称 | 与项目名称保持一致 |
| B | 工作类型大类 | 配置/数据库操作/多系统联调 |
| C | 工作类型小类 | 对应大类的内容属性 |
| D | 工作名称 | 简洁描述该项工作 |
| E | 工作内容详细描述 | 按子项逐条列出，每项标注人天 |
| F | 非COSMIC送审人天 | 该项工作总人天 |
| G | 投入人数 | 参与该项工作的人数 |
| H | 开始时间 | 格式yyyy-mm-dd |
| I | 结束时间 | 格式yyyy-mm-dd |
| J | 工作地点 | 现场/远程 |
| K | 备注 | 补充说明 |
